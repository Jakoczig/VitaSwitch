# VitaSwitch 1.22

Safer switching between docked and portable configurations.

- Stages replacement configurations and keeps recovery copies during a switch.
- Adds rollback and next-launch recovery for interrupted operations.
- Handles file I/O failures and partial writes more carefully.
- Preserves existing mode presets during setup and saves active-mode edits.
- Checks optional PSVshell and VitaGrafix configurations on each switch.
- Keeps alternative LiveArea artwork available for future switches.
- Updates the VitaSDK build configuration and adds host regression tests.

Back up your configurations before updating. Do not interrupt power while a
switch is in progress. If recovery is needed, keep `.vsw-old` files and consult
the recovery guide.
